# Personal Portfolio Site

A React portfolio site with About, Portfolio, Resume, and Contact sections. Built to present data science, analytics, and machine learning work in one place.

**Live site:** [https://paridhibhardwajj.github.io/personal-project](https://paridhibhardwajj.github.io/personal-project)

## What’s inside

- **About** — background, focus areas, and core skills
- **Portfolio** — featured GitHub projects with source and demo links
- **Resume** — education, internships, leadership, and selected projects
- **Contact** — email, phone, and professional links

## Tech stack

React, CSS, GitHub Pages

## Run locally

```bash
npm install
npm start
```

The app opens at `http://localhost:3000`.

## Deploy

```bash
npm install
npm run deploy
```

This builds the app and publishes it to the `gh-pages` branch.
